# Fayzora AI Lead Desk — Demo Prototype

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Use **Voice Agent Demo** to rehearse English, Hindi, or Marathi demo conversations.
4. Use **Lead Manager** to add/edit leads, import a CSV, and export `fayzora_leads.csv` for Excel.

## Important limitations
- This is a local browser prototype, not a deployed web app and not a live phone dialer.
- Lead records are stored in the current browser's localStorage. Export CSV regularly for backup.
- Google Maps/business discovery, website crawling, CRM/API sync, and actual Excel `.xlsx` generation are not connected yet.
- Real calls are intentionally disabled. Tough Tongue AI setup was not completed because the account's approval/login step was declined. No scenario or dashboard resource creation could be confirmed.
- The Tough Tongue AI account previously reported as Free Tier did not include SIP calling. Before real calls, verify plan eligibility, configure an outbound SIP trunk, ensure sufficient wallet/minutes, use valid E.164 numbers, and review applicable consent/do-not-call rules.
- The uploaded script was used for the playbook and demo flow. It contains both Fayzora and Arcazera wording; this prototype uses the user's confirmed name, Fayzora Technologies.
